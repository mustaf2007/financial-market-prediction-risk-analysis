# Security Policy

## Scope

This repository is a research and educational project, not a production trading service.

## Reporting a vulnerability

Please do not publish credentials, tokens, private keys, or sensitive personal information in public issues. Report suspected security vulnerabilities privately through the repository owner's GitHub contact options.

## Supported release

The final planned development release is V2.2.7. Security and material correctness defects may be reviewed; routine feature expansion is not planned.
